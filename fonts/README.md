# Fonts

Variable fonts the studio inlines into every file it makes, so renders match everywhere with no network. All under the SIL Open Font License 1.1; each folder carries its licence.

- Geist and Geist Mono, Vercel, from the geist npm package
- Inter, Rasmus Andersson, from @fontsource-variable/inter
- Source Serif 4, Adobe, from @fontsource-variable/source-serif-4

Use: `node scripts/font.mjs css "<family>"`. See skills/desk/procedures/fonts.md.
