# Desk Studio in Claude Code

## Install

Use Claude Code 2.1.302. In your terminal, run:

```
claude plugin install desk --marketplace adityareddy-dev/deskstudio
```

## What the plugin installs

The plugin installs the desk briefs and commands.

## Known limits

Checked on 2026-10-25 with Claude Code 2.1.302 and plugin 1.0.2: the install command runs. A first job has not been run from this install.

The plugin installs from the repository, which can be ahead of the npm package. The session and the desks use your model access.
