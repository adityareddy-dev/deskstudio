# The dashboard in use

`/desk:dashboard setup` once, then `/desk:dashboard start`, opens a local page: the 42 desks as bots in four rooms, awake while their agents work, the job moving along its track with the round, score, cost and time, the review board with every rough, the pick and each round's scorecard, and the cost by tier. Every control is a write to a file the Manager reads before its next step: pause, continue, stop, move a tier or a desk to another model, write a desk a note, pick a rough yourself, approve under the bar or send back with notes. The full guide is [the dashboard](dashboard.md).
